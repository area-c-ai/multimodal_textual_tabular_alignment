# tests/

Evaluation/test plans. One markdown file per planned evaluation, following the
convention below. The first plan is
[`shift-summaries-text-only.md`](shift-summaries-text-only.md).

## Convention

- One markdown file per planned evaluation (e.g.
  `tests/shift-summaries-text-only.md`, `tests/comparison-with-owner-project.md`).
- Each plan describes its goal, the data it uses, the method, any LLM
  involved, the measurements it needs (recorded in `../measurements.md`), and
  the expected outputs.
- Plans are placeholders until the analyses are actually defined; do not
  invent details.
- Status line: `planned` / `in progress` / `done` (+ date).
